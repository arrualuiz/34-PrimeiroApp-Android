# Meu primeiro app Android

Projeto "Hello World" criado pelo assistente do Android Studio em 16/08/2026, para testar o ambiente (SDK, emulador e celular com depuração USB) antes de começar o [Notifica Arquivo](https://github.com/arrualuiz/11-AndroidNotificationReader).

- Kotlin + Jetpack Compose
- Pacote `com.example.meuprimeiroapp`
- `minSdk` 24, `targetSdk` 36

A tela mostra só a saudação padrão do modelo (`Hello Android!`).

## Como abrir

1. No Android Studio, **Open** e escolha a pasta `primeiroApp`.
2. Aguarde o Gradle Sync e clique em **Run**.
